# Sub-GHz Protocol Reference Docs

Per-protocol reference documentation for Sub-GHz decoders/encoders.

**Source:** imported from the KAT (KeyFob Analysis Toolkit) project for reference.
KAT's decoders/encoders derive from ProtoPirate and Flipper-ARF reference
implementations. These are documentation only — no code from KAT is used in
this firmware (our Sub-GHz stack is the Flipper subghz protocol lib).
